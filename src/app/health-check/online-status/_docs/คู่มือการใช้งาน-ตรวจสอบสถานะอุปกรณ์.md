## 1. ภาพรวมระบบ

ระบบ **ตรวจสอบสถานะอุปกรณ์** เป็นหน้า Dashboard สำหรับทีม Admin และ CS ใช้ติดตามสถานะการเชื่อมต่อของเครื่อง POS (เช่น SB Canteen, Facial Recognition) ทุกโรงเรียนแบบเรียลไทม์

**ความสามารถหลัก:**

| ความสามารถ | คำอธิบาย |
|---|---|
| ดูสถิติภาพรวม | จำนวนเครื่องทั้งหมด / ออนไลน์ / ออฟไลน์ / กำลังใช้งาน |
| ดูรายโรงเรียน | แสดงสถานะเครื่องแต่ละโรงเรียน จัดกลุ่มตามแอปพลิเคชัน |
| ส่งรายงาน | ส่งสรุปสถานะไปยัง LINE / Discord / อีเมล ได้ทันที |
| ส่งออก Excel | ดาวน์โหลดรายงานสถานะอุปกรณ์ทั้งหมด |
| ควบคุม LINE Bot | เปิด/ปิด Bot แจ้งเตือนอัตโนมัติ (เฉพาะ Admin) |
| ดู Log | ติดตามประวัติการกระทำและประวัติการทำงานของ Bot |
| ลบข้อมูลเก่า | ลบเครื่องที่ไม่ได้ใช้งานเกิน 7 วัน (เฉพาะ Admin) |

## 2. หน้า Dashboard หลัก — การ์ดสรุปสถิติ

เมื่อเข้าหน้านี้ ระบบจะโหลดข้อมูลสถิติภาพรวมให้อัตโนมัติ แสดงเป็นการ์ดสรุป 5 ใบ:

```
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│  อุปกรณ์ทั้งหมด  │  │ โรงเรียนที่มีเครื่อง│  │    ออนไลน์      │  │    ออฟไลน์      │  │  กำลังใช้งาน    │
│    [จำนวน] เครื่อง │  │  [จำนวน] แห่ง   │  │  [จำนวน] เครื่อง │  │  [จำนวน] เครื่อง │  │  [จำนวน] เครื่อง │
│                 │  │ ครอบคลุมทุกแอป  │  │  XX% ของทั้งหมด  │  │  [ระดับความรุนแรง]│  │  XX% ของออนไลน์  │
└─────────────────┘  └─────────────────┘  └─────────────────┘  └─────────────────┘  └─────────────────┘
```

**ความหมายสีการ์ด "ออฟไลน์":**

| สี | เงื่อนไข | ความหมาย |
|---|---|---|
| 🟢 เขียว | ออฟไลน์ = 0 | ปกติทุกเครื่อง |
| 🟡 เหลือง | ออฟไลน์ 1–4 เครื่อง | ต้องระวัง |
| 🔴 แดง | ออฟไลน์ ≥ 5 เครื่อง | ระดับวิกฤต |

**การ์ดแยกตามแอปพลิเคชัน** (แสดงเพิ่มเติมถ้ามีข้อมูล):  
ระบบจะแสดงการ์ดเพิ่มสำหรับแต่ละแอป เช่น SB Canteen, Facial Recognition พร้อมจำนวนออนไลน์ของแต่ละแอป

## 3. Logic การตรวจสอบสถานะออฟไลน์

ระบบใช้เงื่อนไขต่อไปนี้ในการตัดสินสถานะเครื่อง:

```
┌──────────────────────────────────────────────────────────────────────┐
│                    เงื่อนไขการตรวจสอบสถานะ                          │
│                                                                      │
│  OnlineTime ล่าสุด ≤ 10 นาทีที่ผ่านมา  ──►  🟢 ออนไลน์            │
│                                                                      │
│  OnlineTime > 10 นาที และ...                                         │
│    Hardware Server ตอบ HTTP 200  ──►  🟡 ออฟไลน์                    │
│                                         (สาเหตุ: อินเทอร์เน็ต       │
│                                          หรือฮาร์ดแวร์เสียหาย)      │
│                                                                      │
│    Hardware Server ตอบ ≠ 200     ──►  🔴 ออฟไลน์                    │
│                                         (สาเหตุ: เซิร์ฟเวอร์         │
│                                          เกิดข้อขัดข้อง)             │
└──────────────────────────────────────────────────────────────────────┘
```

**สรุปสั้น ๆ:**
- เครื่องส่ง heartbeat ทุก ~1 นาที หากไม่ส่งเกิน 10 นาที = ออฟไลน์
- ถ้าเซิร์ฟเวอร์ยังตอบสนองได้ → ปัญหาอยู่ที่เครื่องหรืออินเทอร์เน็ตโรงเรียน
- ถ้าเซิร์ฟเวอร์ไม่ตอบสนอง → ปัญหาอยู่ที่ระบบ Hardware Server

## 4. ปุ่มการดำเนินการรายงาน

ปุ่ม **"การดำเนินการรายงาน"** (สีน้ำเงิน มุมขวาบน) เมื่อกดจะเปิด Dropdown เมนู:

```
┌─────────────────────────────────┐
│  🔔 ส่งรายงานสถานะ              │
│  ─────────────────────────────  │
│  [LINE]  ส่งรายงานไปยัง LINE    │
│  [Discord] ส่งรายงานไปยัง Discord│
│  [✉️]  ส่งรายงานทางอีเมล         │
│  ─────────────────────────────  │
│  📊 ส่งออกข้อมูล                │
│  ─────────────────────────────  │
│  [Excel] ส่งออก Excel           │
│  ─────────────────────────────  │
│  ⚙️ การตั้งค่ากลุ่ม              │
│  ─────────────────────────────  │
│  [✓] กลุ่ม LINE ที่ใช้งานอยู่    │
│      กลุ่ม LINE อื่น ๆ           │
└─────────────────────────────────┘
```

### 4.1 ส่งรายงานไปยัง LINE

**Workflow:**

```
กดปุ่ม "ส่งรายงานไปยัง LINE"
        │
        ▼
ต้องเลือกกลุ่ม LINE ก่อน (ถ้ายังไม่ได้เลือก ปุ่มจะ disabled)
        │
        ▼
ระบบดึงสถานะอุปกรณ์ทุกโรงเรียน
        │
        ▼
ส่งข้อความสรุปไปยังกลุ่ม LINE ที่เลือก
        │
     ┌──┴──┐
   สำเร็จ  ล้มเหลว
     │         │
   แจ้ง ✅   แจ้ง ❌
```

> **หมายเหตุ:** หากมีเครื่องออฟไลน์และเลือกกลุ่มแล้ว จะเห็น Badge แสดงจำนวนเครื่องออฟไลน์ข้างปุ่ม

### 4.2 ส่งรายงานไปยัง Discord

เหมือน LINE แต่ส่งไปยัง Discord Webhook ไม่ต้องเลือกกลุ่ม กดได้เลย

### 4.3 ส่งรายงานทางอีเมล

ส่งรายงานสถานะเครื่อง POS ทั้งหมดทางอีเมลให้ทีมที่กำหนดไว้ในระบบ

### 4.4 ส่งออก Excel

ดาวน์โหลดไฟล์ Excel รายงานสถานะอุปกรณ์ทั้งหมด เหมาะสำหรับเก็บบันทึกหรือส่งต่อ

### 4.5 เลือกกลุ่ม LINE

ใช้เลือกกลุ่ม LINE ที่จะรับรายงาน กลุ่มที่กำลังใช้งานจะมีเครื่องหมาย ✓ สีเขียว

## 5. ปุ่มตั้งค่า (เฟือง)

ปุ่มรูปเฟือง (ถัดจากปุ่มรายงาน) เปิด Dropdown เมนูสำหรับการตั้งค่าและจัดการ:

```
┌─────────────────────────────────────┐
│  [LINE]  ทดสอบ LINE Webhook         │
│  [🔗]   กลุ่ม LINE รายโรงเรียน      │
│  ────────────────────────────────   │
│  ⚡ ควบคุม LINE Bot                  │
│  ────────────────────────────────   │
│  LINE Bot แจ้งเตือน                  │
│  กำลังทำงาน / หยุดทำงาน    [Switch]  │
│  ────────────────────────────────   │
│  🗑️ จัดการข้อมูล                     │
│  ────────────────────────────────   │
│  ลบเครื่องที่ไม่ได้ใช้งานเกิน 7 วัน   │
└─────────────────────────────────────┘
```

### 5.1 ทดสอบ LINE Webhook

พาไปยังหน้าทดสอบการส่งข้อความผ่าน LINE Webhook เหมาะสำหรับตรวจสอบว่า LINE Bot เชื่อมต่อได้ปกติ

### 5.2 กลุ่ม LINE รายโรงเรียน

พาไปยังหน้าจัดการ Mapping ระหว่างกลุ่ม LINE และโรงเรียนแต่ละแห่ง

### 5.3 เปิด/ปิด LINE Bot (เฉพาะ Admin)

```
Switch เปิด  ──►  Bot จะส่งแจ้งเตือน LINE ตามตารางเวลาที่ตั้งไว้
Switch ปิด   ──►  Bot หยุดส่งทั้งหมด แม้ Cronjob ยังทำงานอยู่เบื้องหลัง
```

> **สำคัญ:** เฉพาะผู้ใช้ที่มีสิทธิ์ Admin เท่านั้นที่สามารถเปลี่ยนสถานะ Bot ได้ ผู้ใช้ทั่วไปจะเห็น Switch แต่จะกดไม่ได้

### 5.4 ลบเครื่องที่ไม่ได้ใช้งานเกิน 7 วัน (เฉพาะ Admin)

**Workflow การลบ:**

```
กด "ลบเครื่องที่ไม่ได้ใช้งานเกิน 7 วัน"
        │
        ▼
ระบบโหลด Preview — นับจำนวนเครื่องที่ตรงเงื่อนไข
        │
        ▼
แสดง Modal ยืนยัน:
  - จำนวนเครื่องที่จะถูกลบ
  - โรงเรียนที่ได้รับผลกระทบ
  - เกณฑ์วันที่ตัดข้อมูล
        │
   ┌────┴────┐
 ยืนยัน      ยกเลิก
   │
   ▼
ระบบลบข้อมูลถาวร (ไม่สามารถย้อนกลับได้)
   │
   ▼
แจ้งผลสำเร็จ + รีโหลด Dashboard
```

> **คำเตือน:** การลบนี้ถาวร ไม่สามารถกู้คืนได้ ควรตรวจสอบตัวเลขใน Modal ก่อนยืนยันทุกครั้ง

## 6. Tab: ดูอุปกรณ์ตามรายชื่อโรงเรียน

Tab แรก — แสดงรายการอุปกรณ์จัดกลุ่มตามโรงเรียน

### โครงสร้างการแสดงผล

```
[เลือกโรงเรียน ▼]
        │
        ▼
┌──────────────────────────────────────────────────────┐
│  โรงเรียน ABC                                        │
│  ──────────────────────────────────────────────────  │
│  ▼ SB Canteen              [ออนไลน์ 3] [ออฟไลน์ 1]  │
│  │  ┌────────────────────────────────────────────┐   │
│  │  │ ชื่อเครื่อง │ สถานะ │ เวลาล่าสุด │ ...     │   │
│  │  └────────────────────────────────────────────┘   │
│  ▼ Facial Recognition      [ออนไลน์ 2] [ออฟไลน์ 0]  │
│     ┌────────────────────────────────────────────┐   │
│     │ ชื่อเครื่อง │ สถานะ │ เวลาล่าสุด │ ...     │   │
│     └────────────────────────────────────────────┘   │
└──────────────────────────────────────────────────────┘
```

**การใช้งาน:**
1. เลือกโรงเรียนจาก Dropdown ด้านบน
2. ระบบดึงข้อมูลสถานะอุปกรณ์ของโรงเรียนนั้น
3. อุปกรณ์แต่ละกลุ่ม (ตามแอปพลิเคชัน) แสดงเป็น Collapse ที่กาง/ย่อได้
4. แต่ละแถวแสดง: ชื่อเครื่อง, สถานะ, เวลา Online ล่าสุด

**สถานะที่แสดงในตาราง:**

| สัญลักษณ์ | ความหมาย |
|---|---|
| 🟢 ออนไลน์ | เครื่องส่ง heartbeat ภายใน 10 นาทีที่ผ่านมา |
| 🔴 ออฟไลน์ | เครื่องไม่ส่ง heartbeat เกิน 10 นาที |

**ส่วนตั้งค่าการแจ้งเตือน LINE (ภายใน Tab นี้):**  
แต่ละโรงเรียนมีส่วน "ตั้งค่าการแจ้งเตือน LINE" ที่พับเก็บได้ ใช้กำหนด:
- ช่วงเวลาที่อนุญาตให้แจ้งเตือน (เช่น 06:00–08:00, 15:00–17:00)
- ความถี่การแจ้งเตือนซ้ำ (รอบแรก / รอบถัดไป)

## 7. Tab: Log การกระทำ

บันทึกประวัติการใช้งาน API ของระบบ เหมาะสำหรับ Audit Trail

### ข้อมูลที่แสดง

| คอลัมน์ | คำอธิบาย |
|---|---|
| วันที่/เวลา | วันและเวลาที่เกิดเหตุการณ์ |
| Endpoint | API ที่ถูกเรียกใช้ |
| Method | HTTP Method (GET, POST, PATCH, DELETE) |
| สถานะ | HTTP Status Code (200, 400, 500 ฯลฯ) |
| ระยะเวลา | เวลาที่ใช้ตอบสนอง (มิลลิวินาที) |

### การกรองข้อมูล

- กรองตามวันที่ช่วงเวลา (วันเริ่มต้น — วันสิ้นสุด)
- ค้นหาตาม Endpoint
- ดูได้ทีละหน้า (Pagination)

## 8. Tab: ประวัติ Bot

แสดงประวัติการทำงานของ LINE Bot (Cronjob ที่รันทุก 1 นาทีในช่วงเวลาที่กำหนด)

### ข้อมูลที่แสดง

```
┌────────────┬──────────────────────────────────────┬────────────────┬──────────────────────┐
│  สถานะ     │        สรุปผลการส่ง                  │  ระยะเวลา      │    เวลาที่ทำงาน      │
├────────────┼──────────────────────────────────────┼────────────────┼──────────────────────┤
│  ✅ สำเร็จ │  ✅ 5 โรงเรียน  ❌ 0  ⏭ 12 ข้าม     │    1,234 ms    │  08 พ.ค. 68 07:30:00 │
│  ✅ สำเร็จ │  ✅ 5 โรงเรียน  ❌ 0  ⏭ 12 ข้าม     │      987 ms    │  08 พ.ค. 68 07:29:00 │
│  ❌ ล้มเหลว│  ✅ 3 โรงเรียน  ❌ 2  ⏭ 12 ข้าม     │    2,100 ms    │  08 พ.ค. 68 07:28:00 │
└────────────┴──────────────────────────────────────┴────────────────┴──────────────────────┘
```

**ความหมายคอลัมน์ "สรุปผลการส่ง":**

| ตัวเลข | ความหมาย |
|---|---|
| ✅ N โรงเรียน | จำนวนโรงเรียนที่ Bot ส่งแจ้งเตือนสำเร็จ |
| ❌ N | จำนวนโรงเรียนที่ส่งแจ้งเตือนล้มเหลว |
| ⏭ N ข้าม | จำนวนโรงเรียนที่ข้ามไป (นอกช่วงเวลา หรือไม่มีเครื่องออฟไลน์) |

**การกรองข้อมูล:**  
สามารถกรองตามช่วงวันที่ได้ และมี Pagination รองรับข้อมูลจำนวนมาก

    │  Dashboard    │  กลุ่ม LINE   │  สถานะ Bot    │

    └───────────────┴───────────────┴───────────────┘
                    │
                    ▼
        แสดงการ์ดสถิติ + แถบ Tab
                    │
            ┌───────┴────────┐
            │                │
        Tab ดูโรงเรียน    Tab Log / Bot

## 10. คำถามที่พบบ่อย (FAQ)

**Q: ทำไมเครื่องบางเครื่องแสดงเป็นออฟไลน์ทั้งที่เปิดอยู่?**  
A: เครื่องส่ง heartbeat ทุก ~1 นาที หากอินเทอร์เน็ตโรงเรียนขัดข้องชั่วคราว เครื่องอาจขึ้นเป็นออฟไลน์ได้ รอสักครู่แล้วรีเฟรชหน้า หากยังแสดงออฟไลน์ ให้ติดต่อโรงเรียนตรวจสอบเครือข่าย

**Q: LINE Bot ส่งแจ้งเตือนได้แค่ช่วงเวลาไหน?**  
A: ขึ้นอยู่กับการตั้งค่าของแต่ละโรงเรียน (ค่าเริ่มต้น: รอบเช้า 06:00–08:00 และรอบบ่าย 15:00–17:00) สามารถปรับได้ในแต่ละโรงเรียนบน Tab "ดูอุปกรณ์ตามรายชื่อโรงเรียน"

**Q: ปุ่มส่งรายงาน LINE เป็นสีเทา กดไม่ได้?**  
A: ต้องเลือกกลุ่ม LINE ที่จะรับรายงานก่อน — ไปที่เมนู "การดำเนินการรายงาน" → ส่วน "การตั้งค่ากลุ่ม" → เลือกกลุ่มที่ต้องการ

**Q: ใครสามารถเปิด/ปิด Bot ได้?**  
A: เฉพาะผู้ใช้ที่มีสิทธิ์ Admin เท่านั้น ผู้ใช้อื่นจะเห็น Switch แต่กดไม่ได้

**Q: ลบเครื่องเก่าแล้วสามารถกู้คืนได้ไหม?**  
A: ไม่ได้ การลบนี้ถาวร ควรตรวจสอบตัวเลขใน Modal ก่อนยืนยัน และควรทำเฉพาะเมื่อแน่ใจว่าเครื่องเหล่านั้นไม่ได้ใช้งานแล้วจริง ๆ

**Q: Tab "ประวัติ Bot" แสดงข้อมูลย้อนหลังได้นานแค่ไหน?**  
A: แสดงข้อมูลทั้งหมดที่มีในฐานข้อมูล กรองตามช่วงวันที่ได้ แสดง 20 รายการต่อหน้า

**Q: ส่งออก Excel ได้ข้อมูลอะไรบ้าง?**  
A: รายงานสถานะอุปกรณ์ทั้งหมด รวมถึงชื่อโรงเรียน ชื่อเครื่อง แอปพลิเคชัน สถานะออนไลน์/ออฟไลน์ และเวลา Online ล่าสุด
